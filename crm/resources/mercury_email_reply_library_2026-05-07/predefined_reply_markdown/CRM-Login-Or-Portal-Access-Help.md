# USCPB Safe - CRM Login Or Portal Access Help

This file follows the root workspace instructions in `D:\GithubRepos\AGENTS.md`.

Owner: Aurora  
Primary user: Mercury  
Channel: Email, CRM ticket, chat  
Risk level: Low

## Use Case

Use when a client cannot find the portal, needs the correct CRM link, or needs general login guidance.

## Client-Facing Reply

```text
Hello [Client Name],

Thank you for your message. The secure client portal is available here:

https://uscapitalprivatebank.com/crm/

If you already have an account, please log in with your registered email address. If you are new, please register and then open a support request so the correct department can assist you.

If you are having trouble logging in, please use the password reset option on the portal and let us know if the issue continues.

Thank you,
[Signature]
```

## Do Not Use When

Do not ask for or receive passwords, one-time codes, recovery codes, or private authentication links.
